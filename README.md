# Mewgenics Multi

Mod coopératif non officiel pour Mewgenics, de 2 à 4 joueurs. Chacun garde sa
maison et ses chats, et vous avancez ensemble dans l'histoire et les aventures.

Construit sur [mgmp](https://github.com/SanTertrust/mgmp) de SanTertrust
(licence MIT), qui synchronise déjà les combats et les aventures à deux.

**État :** en développement. Version du jeu visée : 1.1.21239.

Ce mod ne contient aucun code, aucune image ni aucune donnée de Mewgenics : il
lit les fichiers du jeu installé sur ta machine. Mewgenics est un jeu de Tyler
Glaiel et Edmund McMillen.
