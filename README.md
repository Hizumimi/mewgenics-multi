# Mewgenics Multi

**Chacun sa maison et ses chats, l'aventure ensemble !**
Mod coop non officiel pour Mewgenics, de 2 à 4 joueurs, sous Windows, Linux et
Steam Deck, dans les dix langues du jeu.

**→ [La page du mod](https://hizumimi.github.io/mewgenics-multi/)** : ce qu'il
apporte, l'installation pas à pas, comment jouer ensemble.

| Télécharger | |
|---|---|
| Windows | [Mewgenics-Multi-Windows.zip](https://github.com/Hizumimi/mewgenics-multi/releases/latest/download/Mewgenics-Multi-Windows.zip) |
| Linux / Steam Deck | [Mewgenics-Multi-Linux.zip](https://github.com/Hizumimi/mewgenics-multi/releases/latest/download/Mewgenics-Multi-Linux.zip) |

Pour Mewgenics 1.1.21239 (Steam). Le zip contient un `LISEZ-MOI.txt` avec toute
l'installation. Toutes les versions : [releases](https://github.com/Hizumimi/mewgenics-multi/releases).

*English:* an unofficial 2–4 player co-op mod for Mewgenics. Everyone keeps their
own house and cats, and you share the village and the adventures. Windows, Linux
and Steam Deck play together. Install guide in ten languages on the
[mod page](https://hizumimi.github.io/mewgenics-multi/).

Mewgenics est un jeu d'Edmund McMillen et Tyler Glaiel. Ce mod non officiel n'a
aucun lien avec ses auteurs : il ne contient aucun code, aucune image ni aucune
donnée du jeu, et lit les fichiers du jeu installé sur ta machine.
